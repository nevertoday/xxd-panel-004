# XXD Panel 004 · 在地现实与现代线描生成核心

严格把调用方提供的当前主题、已核实信息、参考图片与现实场景定调图作为唯一内容来源。不要借用样张、其他任务或历史成品的地点、建筑、标牌、人物、配色与文案。

只生成已经锁定的**线描设计画框**：上下双联的下方、左右双联的右侧，或纯设计版／壁纸的完整画布。不得在设计画框内部再次生成现实场景、摄影面板、分界线、边框、设备样机或摄影预留区。

## 0. 不可改变的美学动机

每个设计画框必须呈现：

**一个经过确认、完整统一且具有日常温度的现实场景定调图 → 锁定其中最有辨识度的主体、天际线、街道界面、招牌节奏、交通设施、橱窗关系、人群状态或结构记忆 → 提炼而不是机械描摹 → 用纤细准确的单线、清晰几何透视、有秩序的细节节奏、克制留白与适度抽象重新设计 → 从主题的气候、光线、时间、材料、历史、商业、饮食、自然与情绪中推导单色或极少量配色 → 让主标题与可靠的地点信息共同进入线描网格。**

这不是景点拼贴、旅游宣传册、明信片、城市图标包或通用天际线。地点感来自真实空间关系、在地文字、建筑界面、设施和日常节奏；非地点主题则来自其身份、轮廓、结构、姿态、关系和视觉记忆。

## 1. 现实场景事实锁

在内部判断但不输出分析：

1. 确认现实场景定调图与用户主题、参考图片、地址、坐标和事实信息一致。
2. 地点主题锁定至少三个在地线索：空间布局、街道方向与尺度、建筑界面、关键开口、店铺／招牌节奏、交通设施、橱窗关系、人群活动、当地文字、材料、气候或时间。
3. 非地点主题锁定至少三个身份线索：轮廓、结构、姿态、方向、连接、负形、比例或关系距离。
4. 选出一个主层级和一条阅读路径，不能让多个地标、食物、人物和符号竞争。
5. 场景里的当地语言、店招、地址、坐标、年份和专名只有可靠时才能保留；不确定就删除或弱化，绝不杜撰。

## 2. 纤细准确的线描转译

- 选择最能识别主题的天际线、街道界面、道路透视、立面节奏、招牌序列、交通构件、橱窗关系、人群状态或主体轮廓。
- 使用纤细、清楚、准确的单线重建，保留几何透视、遮挡与比例关系，但不逐像素描边。
- 通过线条疏密、间距、重叠、留白比例和少量局部压重制造丰富度，不使用写实明暗塑造。
- 线条应干净而不僵硬，可带极轻纸面吸墨或印刷触感；避免速写乱线、铁丝式缠绕、刺、结、卡通粗边、光滑图标包和 3D。
- 主题必须在缩略图尺寸仍可一眼识别；删减细节不能删掉身份。

## 3. 几何秩序与留白

- 允许少量水平基线、纵向构成线、透视辅助线或简单几何元素，用来组织街道、建筑、文字和阅读节奏。
- 每条辅助线必须服务透视、对齐、层级或节奏，不能成为装饰。
- 构图统一、安静、现代、灵动而克制；不把元素均匀铺满，也不把一个地标夸张成旅游徽章。
- 不画缩略地图、景点九宫格、邮票边框、旅行贴纸、旗帜拼盘或无关图标。

## 4. 主题专属的克制配色

- 从主题的气候、自然光、时间感、建筑材料、历史气息、商业温度、饮食印象、自然环境与情绪质地中推导主色与底色。
- 优先使用单色印刷美学，或一至三种极克制颜色。通过明度、线密度、局部压重和留白形成层次。
- 若有参考图，主要色彩关系必须能从定调图解释；若只有主题，颜色必须与可靠的场景事实一致。
- 禁止固定模板色、国旗配色、通用复古米色、明信片夕阳、彩虹填色、荧光色和大面积数字渐变。

## 5. 004 专属文字系统

文字是**收藏级旅行海报／城市品牌式的信息层级**，不是后贴说明标签。

- 自动文案以用户主题形成一个明确主标题。零至三条辅助信息可使用主题原文、自然的当地语言、可靠的国家／地区、地址、坐标、编号、年份或一句极短事实说明。
- 不得发明地址、坐标、年份、当地拼写、地标、店名或口号。画面中的街头文字和店招必须清晰、自然、专业；不能可靠呈现时宁可省略。
- 主标题醒目但不压过场景身份；辅助文字更小，以网格、基线、边距和线描结构共同组织。
- 为中文、日文、韩文、阿拉伯文与拉丁文字选择各自自然的现代编辑字形、标点、间距、塑形与语义换行。阿拉伯文使用真正从右向左的组合。
- 用户最终成稿逐字保留。无字模式中不得出现标题、店招、数字或伪文字；若事实场景无法避免文字，需将其转化为非文本结构而不是乱码。

## 6. 当前模式与壁纸

调用方会附上唯一当前模式、准确尺寸、现实场景可见性和锁定文案。只执行附加块：

- 双联只生成线描设计画框；现实场景定调图由外部独立准备并精确拼合。
- 纯设计版与壁纸不显示现实场景、分界线或摄影预留区。
- 每张壁纸按设备宽高比重新组织主题线索、透视、留白、标题网格与系统 UI 安全区；不绘制时钟、图标、Dock、控件或设备框。
- 连贯壁纸中，现实场景定调图锁定内容与事实，iPad 线描定调图只锁定抽象语法、透视纪律、线重、配色、留白和文字系统。不得裁切或顺序垫图。

## 7. 生成前检查

1. 现实场景与主题、参考、地址或坐标一致，没有景点拼贴或杜撰地点事实。
2. 至少三个主题专属线索在设计中保留，缩略图仍可识别。
3. 线条纤细准确、透视清楚、细节节奏有序，是提炼而非机械描摹。
4. 水平、纵向和几何辅助元素都服务结构，没有装饰性乱线、图标散落或复杂场景复制。
5. 单色或极少量配色来自主题气候、光线、材料与文化情绪，不是固定模板。
6. 标题与辅助信息准确、自然、符合目标语言；地址、坐标、年份、店招和专名都有可靠依据。
7. 当前模式、尺寸、现实场景可见性、壁纸安全区和文案设置服从附加块。
8. 没有拼贴总览、Logo、水印、UI、样机、邮票边框、旅游贴纸或第二焦点。
