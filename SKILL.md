# XXD Panel 004 · 在地现实与现代线描

Turn each supplied theme or reference into one credible, coherent reality scene and a refined graphic-line interpretation of that same scene. Paired modes show the reality scene; design-only and wallpapers show only the line design. For a real place, preserve verified spatial relationships, local text systems, street interfaces, facilities, materials, and everyday rhythm. For a non-place theme, preserve its defining identity, structure, gesture, relation, and visual memory.

Operational rules follow the shared XXD Panel workflow contract: four combinable modes; an explicitly confirmed whole-canvas ratio or exact resolution before generation; single complete-canvas raster generation by default; high-fidelity source reference in paired modes; linked or independent four-device wallpapers; copy and locale preflight; fresh generation jobs; privacy-preserving raster generation; deterministic composition as fallback only; and one fresh task directory per source and mode. Style-specific sections refine aesthetics and copy but never override this contract.

## Non-negotiable contract

- One theme or reference set may be processed in one or more selected modes. Each selected ordinary mode (`top-bottom`, `left-right`, `design-only`) produces one PNG; selected `wallpaper-pack` produces exactly four separate PNGs. Selecting all four modes therefore produces seven final files per input. Keep every mode in its own task directory and never combine modes, inputs, or wallpapers into a grid, contact sheet, or overview.
- Input may be a theme alone or may include a place name, address, coordinates, factual notes, or reference images. Reference images are authoritative visual evidence. A theme-only task first establishes one fresh reality-scene anchor; every selected mode in that invocation derives from that same approved anchor unless the user requests independent interpretations.
- Resolve a non-empty ordered set of modes before generation: `top-bottom`, `left-right`, `design-only`, and/or `wallpaper-pack`. Accept one choice, multiple choices separated by `+`, Chinese/English commas or whitespace, natural-language names, or `全部` / `all`. Deduplicate repeated choices and execute in menu order 1→4. If none is specified, ask with the multiline multi-select menu in the workflow. Do not ask again when the set is already clear.
- When the selected set contains `wallpaper-pack`, require a second choice: `linked` or `independent`. A linked pack approves one line-design anchor wallpaper, iPad by default, and makes every other device reference both the same reality-scene anchor and that line-design anchor. An independent pack gives every device only the same reality-scene anchor. Neither permits resizing or cropping one wallpaper into the others.
- Paired modes target a visually equal 50/50 relationship within one coherent generated canvas. Minor generative deviation is acceptable unless the user explicitly requires pixel-exact halves; exact deterministic geometry belongs to the documented fallback. `design-only` and every wallpaper contain no visible reality scene, no seam, and no reserved photographic panel.
- The whole final canvas ratio or exact pixels must be explicitly resolved before generation. Offer the archived/original-prompt 3:4, source aspect as an explicit choice, common ratios, or custom ratio/pixels; never infer explicitly selected final-canvas dimensions silently. Exact pixels take precedence over an explicitly chosen ratio.
- A supplied visible photograph remains faithful. Allow only restrained editorial grading and environmental extension needed for an explicitly overridden canvas. A generated reality scene remains faithful to verified theme facts and must be a single unified slice of life, not a collage of attractions.
- The transformed frame must preserve at least three scene- or theme-specific cues while converting the same reality anchor into fine accurate single-line geometry, clear perspective, ordered detail rhythm, restrained whitespace, and limited theme-derived colour. It is not mechanical tracing, decorative doodling, generic skyline clip art, cartoon, 3D render, or unrelated flourish.
- Copy has no silent default. Resolve automatic copy, exact custom copy, or text-free output before image generation. Automatic and custom modes also require a target language or locale. By default, one source-specific copy package is shared verbatim across all selected modes; explicit per-mode copy instructions override it.
- Render no logo, watermark, signature, colour swatch, UI, device mockup, decorative pseudo-text, or unrelated explanatory prose.

## Aesthetic motive lock

Modes and device ratios may change placement and aspect ratio but never the 004 motive. Every transformed frame must visibly express this chain:

**one verified, coherent, everyday reality scene anchored in the user's theme → lock its most recognisable subject, skyline, street interface, sign rhythm, transport element, shopfront relation, human state, or structural memory → distil rather than trace → rebuild with fine accurate single line, clear geometric perspective, ordered detail rhythm, and measured abstraction → use a theme-specific monochrome or very limited palette derived from climate, light, time, material, history, commerce, food memory, nature, and mood → integrate an assertive title and disciplined supporting information as part of the poster structure**.

The sense of place comes from spatial and cultural evidence, not from collecting famous attractions or adding generic lanterns, taxis, cafés, flags, food icons, or postcard sunsets. Modernist line posters, collectible travel editions, city-brand systems, art publishing, and experimental editorial design are construction influences rather than templates.

Reject the result as generic when another city or theme could replace the input without materially changing the reality scene, line structure, perspective, local text, palette, or copy. Also reject landmark collage, exaggerated monuments, tourist-brochure gloss, postcard clichés, fabricated signage, decorative doodles, smooth icon packs, dense colour fill, 3D volume, and unrelated brand styling.

## 004 visual system

### Credible reality anchor

- When the user supplies a photo, address, coordinates, or factual reference, treat it as evidence and never substitute another place or generic scene.
- For a city or location, lock spatial layout, building interface, street width and direction, shopfront/sign rhythm, transport facilities, human activity, local script, materials, climate, and time of day only where supported.
- For a broad city theme, compose one credible slice of everyday life where people, buildings, streets, signs, windows, facilities, food, commerce, and activity coexist naturally. Do not paste separate attractions together.
- People keep pose, direction, clothing mass, and relational distance; animals keep body rhythm and head direction; plants keep growth gesture; architecture keeps skyline and defining openings; objects and vehicles keep functional silhouette and negative shape; landscapes keep one source-specific terrain or spatial relation.
- For a non-place theme, lock the principal identity, silhouette, structure, gesture, relation, and visual memory. In every case, approve one reality-scene anchor before line extraction.

### Distilled line composition

- Select the anchor's most recognisable skyline, façade rhythm, road geometry, signage cadence, transport fixture, window relation, people state, or subject contour.
- Rebuild it with fine accurate single line, clear geometric perspective, measured abstraction, controlled whitespace, and an ordered rhythm of detail. Do not mechanically trace every edge.
- A few horizontal baselines, vertical construction lines, or geometric guides may clarify perspective and rhythm. Every auxiliary element must serve structure.
- Keep one hierarchy and one reading path. Avoid clutter, arbitrary curves, icon scattering, literal miniature maps, and decorative enrichment.

### Fine precise line and tonal rhythm

- Keep line predominantly fine, crisp, and accurate, with subtle density changes and occasional local weight for hierarchy.
- Use perspective, overlap, line spacing, blank-to-mark ratio, and selective darkening to create richness without realistic shading.
- Preserve a clean print or lightly tactile paper character. Avoid shaky expressive wire, thorns, knots, sketch noise, comic outlines, photoreal light, 3D modelling, and glossy vector effects.

### Theme-specific restrained colour

- Derive colour from the theme's climate, light, time, architecture, material, history, commerce, food memory, nature, and emotional texture.
- Prefer monochrome print aesthetics or a very small restrained palette. Vary density, value, local weight, whitespace, and detail rhythm rather than filling many regions.
- Do not impose a fixed palette, postcard sunset, national-flag scheme, generic retro beige, rainbow colour, or unrelated city-brand colour.

## Copy and typography belong to 004

004 typography behaves like a disciplined collectible travel poster or city-brand system, integrated with the scene and line structure rather than pasted on afterward.

- Automatic copy uses one clear principal title from the user's theme. Supporting text may use the theme's original wording, native local language, verified country/region, address, coordinates, number, year, or one short factual note.
- Never invent addresses, coordinates, years, local spellings, landmarks, or slogans. Street and storefront text visible in the scene must be accurate, natural, legible, and professionally spelled.
- Preserve exact user wording verbatim. Refine an editable direction only within permission while protecting audience, mandatory terms, tone, and semantic phrase breaks.
- Apply the unrelated-image swap test: generic lifestyle words that survive on another source must be rewritten.

Typography has its own 004 construction:

- **Role:** title establishes identity; supporting text supplies verified place or edition context.
- **Voice:** clear, modern, quiet, cultured, and locally credible.
- **Construction:** one prominent title with a disciplined hierarchy of zero to three smaller elements; adapt proportions and line breaks to the resolved script.
- **Placement:** integrate title, line drawing, baselines, and margins into one grid. Never cover the key scene identity or float as an afterthought.
- **Material:** clean print, fine ink, or subtly tactile letterpress consistent with the line system.
- **Script:** use a native hand-made editorial equivalent for the resolved locale. Preserve natural Chinese, Japanese, Korean, Arabic, and Latin construction rather than imitating Latin handwriting across every script.

Resolve locale independently from command language:

```text
target market or audience > requested output language > direction language; if none is explicit, ask before generation
```

Localise by transcreation using native wording, rhetoric, punctuation, spacing, shaping, and semantic line breaks. Never infer nationality or audience language from appearance, clothing, scenery, filenames, metadata, or signs.

5. Start a fresh job and reserve collision-safe output directories before generation. Use only the current invocation's explicit source or theme. Read `references/xxd-panel-004-prompt.en.md` or `references/xxd-panel-004-prompt.zh-CN.md` immediately before building the generation request.
